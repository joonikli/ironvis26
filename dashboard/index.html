Four of six campus groups already use AI efficiently. If Dev and Sandbox matched them, CMU would spend less and use less energy every month.

4 · Recommendations

Build habits that will still work when the models change

Lasting habit works with any model. Expiring detail names a model or price that will change; check it again at each model switch.

Limits

  • The data is synthetic (202,650 requests, Oct 1–30 2026, two providers, six groups). It contains none of the anomalies described in the competition slides (no 500 errors, no runaway loops, no time-of-day peaks), so we did not analyze them.
  • Energy and carbon are estimates, not measurements: published per-model benchmarks scaled by token counts. Gemini and o1-preview use stand-in benchmarks. Carbon depends mostly on which power grid serves the data center, which the logs don't say.
  • Failed requests (400 and 429 errors) are not billed and have no token counts, so they count as $0 and 0 Wh here. Their real cost is wasted time.
  • Savings assume habits change without changing the work itself. The data can't confirm this.
